#  Dashboard Admin

A simple and modern admin panel for managing an online book store.  
You can view statistics and charts, and manage users and books using Firebase.

---

##  Technologies & Tools

- React
- JavaScript (ES6+)
- HTML & CSS
- Firebase (Realtime Database + Authentication)
- Material UI
- Recharts (for charts)

##  Getting Started (Local Setup)

1. Clone the repository:

```bash
git clone https://github.com/zeinabhoma/Dashboard-Admin.git
```

2. Navigate to the project folder and install dependencies:

```bash
cd Dashboard-Admin
npm install
```

3. Start the development server:

```bash
npm start
```

---

##  Features

- View overall statistics and charts
- User list with add/edit/delete functionality
- Book list with add/edit/delete functionality
- Connected to Firebase (live database)
- Responsive and modern UI using Material UI
